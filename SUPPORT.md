# Support

Use the issue tracker in the affected repository for reproducible bugs,
documentation gaps, and focused feature requests.

Before opening an issue:

1. upgrade to the latest release line;
2. check the package README and the
   [hayate documentation](https://hayatepy.github.io/hayate/);
3. include a minimal reproduction, Python version, and runtime.

Security vulnerabilities must be reported privately as described in
[SECURITY.md](SECURITY.md).

Teams evaluating a real API, MCP backend, or Workers deployment can apply to
the bounded [design-partner program](docs/DESIGN_PARTNERS.md). The program is
not a production SLA or a replacement for the issue tracker.
